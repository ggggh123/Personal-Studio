# 聊天思考态轮播提示 `ThinkingIndicator` 设计

日期：2026-06-17
状态：已获批,待实现

## 背景与目标

模型思考(尤其推理模型出首字前)时,UI 只有一个闪烁绿光标 + 空 `AiFrame`,像卡死。目标:类比 Claude Code,在思考空窗期显示**一组幽默轮播提示词 + 已思考秒数**,让用户知道是模型在想而非软件卡住。纯 UI,无数据/网络/DB 改动。

## 决策(已确认)

- 风格:**终端黑话 + 混搭教务/学生梗**,共 **24 条**。
- **显示已思考秒数**。
- 每 **3 秒**换一句;`offset` 随机起始,避免每次都从第一句。

## 渲染点

`ChatDetailScreen` 流式项 `if (state.streamingText != null)` 内:`streamingText` 为空(思考中、未出字)→ `ThinkingIndicator()`;非空→原 `TypewriterText`。`AiFrame` 头部仍是模型名。推理模型出首字前正是此空窗期(reasoning_content 被 contentOrNull 跳过,无 Delta,`streamingText` 维持 "")。

## 组件 `feature/chat/ui/ThinkingIndicator.kt`

- `val THINKING_PHRASES: List<String>`(24 条,见下)。
- 纯函数 `fun thinkingPhraseAt(elapsedSeconds: Int, offset: Int): String = THINKING_PHRASES[(offset + elapsedSeconds / 3) % THINKING_PHRASES.size]`(每 3s 进一句,取模循环)。
- `@Composable fun ThinkingIndicator(modifier)`:`offset = remember { Random.nextInt(size) }`;`elapsed` 由 `LaunchedEffect` 每 1s+1;一行显示 `<thinkingPhraseAt(elapsed,offset)>`(Phosphor) + `⟨elapsed⟩s`(FoamDim) + 复用 `BlinkingCursor`。进流式项即新建→每次发送 elapsed 从 0 起。

## 测试

- 单测 `ThinkingPhrasesTest`:`THINKING_PHRASES.size==24`;`thinkingPhraseAt` 每 3s 进句(0/2→[0],3/5→[1],6→[2]);offset 偏移 + 取模回卷(offset=24→[0])。
- 真机 DoD:发消息→出字前显轮播提示且秒数在涨、每 3s 换句、出首字即切回正文;长思考推理模型尤其明显。
