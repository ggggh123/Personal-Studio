Principles
  • Everything is a drawing. Corner marks, tick rules, coordinates on every card.
  • All-caps labels, bold geometric sans. Zero serifs.
  • Signal orange is loud. One color does a lot of work.
  • Hard-edged. Square corners, thick keylines, no shadows.
  • Numeric & precise UI copy — "QUERY", "RESPONSE", "ARCHIVE".
  • Intellectual but cold. Looks like a reference manual.
