# 界面改版：天光

[返回项目入口](../README.md)

本文记录 2026-11 起的界面改版：已经定下的设计决定、在 Compose 中的落地方式和分阶段实施计划。设计稿与可点击原型在私有设计画布 [Personal Studio 天光 · 第一批](https://claude.ai/artifact/15LRUqcJedzS42ynuakpzu)（需项目所有者账号或分享权限）。实施完成后，“界面约定”以本文为准，并同步更新 [架构文档](architecture.md#界面约定) 中仍描述 Terminal 主题的段落。

## 已定的设计决定

| 方面 | 决定 |
| --- | --- |
| 信息架构 | 底栏 4 个入口加中心按钮：今日（首页）· 问答 · ＋ · 资料 · 校园。＋ 展开扫描文档、拍题提问、新建待办、添加课程。资料合并知识库与扫描文档。全局设置收进头像入口。取消冷启动 1.3 秒的强制品牌屏。 |
| 主题“天光” | 配色跟随北京坐标的真实太阳高度。浅色族（拂晓 → 上午 → 正午 → 午后 → 日落）与深色族（入夜 → 深夜 → 黎明前）内部连续漂移；深浅切换只在日出前约 12 分钟、日落后约 27 分钟各一次。强调色随时间变化。默认模式为“天光”，另有“跟随系统”“固定浅色”“固定深色”。 |
| 不随时间变化 | 字体、版式、间距、动效参数、课程色（深浅各一套）、状态含义。相机与裁切界面始终深色；学校网页保持原样；成绩分享卡使用固定配色。 |
| 字体 | 标题与大数字用 Noto Serif SC 子集，正文用系统无衬线字体，数字一律等宽。 |
| 动效 | 三档弹簧，可被手势打断；共享元素连续（卡片 → 详情、扫描缩略图 → 编辑器、成绩行 → 详情）；Android 14 起预测式返回；关键节点触感反馈；尊重系统“减少动态效果”。 |
| 首页地平线 | 太阳按真实太阳高度绘制；月相真实，月亮位置按夜晚进度；打开时升起，轻点看日出日落，长按拖动预览一天并实时换肤；日期下方一行标语，数据标语优先于时段标语。 |

## 设计系统在 Compose 中的落地

### 颜色令牌

每个关键帧包含同一组语义令牌：`bg` 页面底、`surface` 卡片、`surfaceRaised` 浮起面板、`text` 正文、`textSecondary` 次要文字、`textTertiary` 装饰与轨迹（不用于文字）、`line` 分隔线、`accent` 强调、`accentSoft` 强调浅底、`onAccent`。遮罩色按深浅族固定。另设 `error` 令牌，只用于表单校验和失败提示文字，取值待阶段 0 定稿（需与强调色在明度上拉开，避免与白天的朱红混淆）；逾期等状态仍用反色胶囊表达。

| 帧 | 锚点 | bg | text | textSecondary | accent | accentSoft |
| --- | --- | --- | --- | --- | --- | --- |
| D 拂晓 | 日出前 12 分钟 → 日出后 36 分钟 | `#ECEEF1` | `#1B1F27` | `#5B616D` | `#9C473C` | `#F2E3E0` |
| M 上午 | 日出后 2.5 小时 | `#F5F3EE` | `#1C1B19` | `#635E56` | `#AE3F27` | `#F6E3DC` |
| O 正午 | 太阳最高 | `#F8F7F3` | `#141311` | `#5F5B54` | `#B03A22` | `#F7E2DA` |
| A 午后 | 日落前 2 小时 | `#F5EFE4` | `#1E1913` | `#665C4E` | `#9C4A1C` | `#F4E1D0` |
| S 日落 | 日落前 18 分钟 → 日落后 27 分钟 | `#F2E5D6` | `#22180F` | `#6A5644` | `#9A3D20` | `#F1DACA` |

| N 深夜 | 日落后 2.6 小时 → 日出前 1.4 小时 | `#13100C` | `#EFE6D8` | `#A99D8A` | `#E3A54E` | `#33291B` |

`surface`、`surfaceRaised`、`textTertiary`、`line`、`onAccent` 的完整取值以设计画布的设计系统板和原型代码为准，落地时整理进 `ui/theme` 的关键帧表。插值在 OKLab 空间进行，段内使用 smoothstep。原型的全年采样（每 5 分钟，夏至、春秋分、冬至）最差对比度：正文 14.1 : 1，次要文字 5.35 : 1，强调 5.3 : 1，强调在浅底上 4.78 : 1。

### 主题引擎

| 组件 | 职责 |
| --- | --- |
| `SolarCalculator` | 离线计算北京坐标（39.96°N, 116.31°E）的太阳高度、日出、日落和正午；不申请定位权限。 |
| `MoonPhase` | 按朔望月近似计算月龄与月相名，误差小于 1 天。 |
| `DaylightPalette` | 由时刻与当日太阳数据得到所属族和插值后的令牌。 |
| `ThemeClock` | 仅在前台时按分钟发出时刻；深浅族变化只在安全时刻生效：回到前台、亮屏、页面切换。其余时间保持当前族，族内照常漂移。 |
| `ThemeMode` 偏好 | 天光（默认）/ 跟随系统 / 固定浅色 / 固定深色。“跟随系统”由系统决定深浅族，时刻只决定族内色温。 |
| `AppTheme` | 通过 `CompositionLocal` 提供令牌、字体、形状和动效；颜色以 900 ms 过渡，拖动预览时 120 ms；同步状态栏与导航栏图标深浅；同时桥接到 `MaterialTheme.colorScheme`，让尚未改版的组件得到协调的默认色。 |

公式渲染页 `assets/katex/render.html` 已经通过 CSS 变量取色；改为在页面就绪时和每次深浅切换时注入新令牌。

### 动效令牌

| 档位 | 响应 / 阻尼 | Compose | 用途 |
| --- | --- | --- | --- |
| 快 | 0.26 s / 0.80 | `spring(dampingRatio = 0.8f, stiffness = 584f)` | 按压、开关、分段指示、＋ 旋转 |
| 标准 | 0.40 s / 0.88 | `spring(dampingRatio = 0.88f, stiffness = 247f)` | 页面切换、面板展开、卡片变换 |
| 柔 | 0.60 s / 0.95 | `spring(dampingRatio = 0.95f, stiffness = 110f)` | 日月升起、整页进入、长距离滑动 |

退出动画使用约 280 ms 的加速曲线，比进入更快。系统关闭动画时，以上全部改为瞬时。

### 字体与体积

原先的 Maple Mono CN 三个字重约 16 MB，另有 VT323 与 Fraunces，已在阶段 0 删除。现在只打包 Noto Serif SC 子集（SemiBold 与 Bold 共约 4.8 MB），正文用系统字体，APK 净减少约 11 MB。

## 迁移策略

现有界面直接引用 Terminal 颜色常量约 1200 处（`Phosphor`、`Foam`、`FoamDim`、`FoamMute`、`Void`、`Amber`、`Carmine`、`Cyan`、`Deep`、`Hull`、`Rule`、`Dim`、`Olive`），分布在 78 个文件中；形状统一为直角，字体为 Maple Mono；`TerminalTopBar` 等终端组件被引用约 140 次，界面文案里另有约 100 处终端装饰符号（`▸`、`──`、`[重试]` 等）。有两种过渡方式：

| 方式 | 做法 | 代价 |
| --- | --- | --- |
| A：过渡映射（推荐） | 保留旧颜色名，但把它们从固定色值改为读取当前天光令牌的 `@Composable` 只读属性（`Void` → bg，`Deep`/`Hull` → surface，`Foam` → text，`FoamMute`/`FoamDim`/`Cyan` → textSecondary，`Rule`/`Dim` → line，`Phosphor`/`Amber` → accent，`Carmine` → error）；主题层替换形状与字体，扫描线与暗角改为空操作，终端组件内部改用新样式，并顺手去掉文案里的终端装饰符号。第一阶段结束时所有旧页面立刻跟随天光变色，之后逐页精修，精修完的页面不再引用旧名，最后删除旧名。 | 在非 Composable 作用域（绘制 lambda、`remember` 初始化等）里读这些常量会编译失败，涉及约 9 个文件，需改为先在组合中取值；旧页面精修前只是“协调”，版式仍是旧的，语义也只是近似（如旧的青色、琥珀色被并入次要色与强调色）。 |
| B：新旧并存 | 旧页面保持 Terminal 主题，直到各自改版。 | 迁移期间新旧两套视觉并存，跳转时反差很大。 |

## 分阶段实施

每个阶段单独成提交，阶段结束时运行 `:app:testDebugUnitTest :app:assembleDebug :app:lintDebug`，并在真机上按五个时刻检查。

### 阶段 0：主题基础（已完成）

- `ui/theme/daylight`：`OkLab`、`SolarCalculator` 与 `MoonPhase`、`DaylightPalette`（8 个关键帧、族内插值、族被“按住”时贴边取色、四种模式）、`FamilyGate`（深浅只在安全时刻切换）、`CoursePalette`。
- `ui/theme`：`AppTheme` 按分钟取色、族切换时 900 ms 交叉淡化、同步状态栏图标深浅、把令牌桥接到 Material；`Tg.colors` / `Tg.daylight` 供新界面使用；`TgMotion` 三档弹簧；`TgTypography`（标题衬线、正文系统字体、全部等宽数字、最小 11 sp）；`TgShapes` 圆角；`DarkCanvas` 让相机、裁边、增强预览和图片裁切始终深色。
- 迁移方式 A：旧颜色名改为读取天光令牌的 Composable 只读属性；在绘制代码里直接读旧色名的 13 个文件已改为先取值；扫描线与暗角改为空操作；44 个文件中 109 处终端装饰文案已去掉；删除 Maple Mono CN、VT323、Fraunces 三套字体（约 16 MB）。
- 公式页改用 `--text`、`--accent` 等令牌变量，Kotlin 端在配色变化时只注入变量、不重新渲染公式。
- 设置页新增“外观”：主题四种模式；调试版另有“固定时刻”（实时 / 拂晓 / 上午 / 正午 / 日落 / 深夜）。
- 测试：冬至与夏至日出日落对照公开数据（4 分钟内）、正午太阳高度、已知新月与满月、8 个关键帧与 2026 全年每 10 分钟采样的 WCAG AA 对比度、每天恰好两次深浅切换且族内无跳变、贴边取色与四种模式、`FamilyGate` 规则。
- 字体：标题衬线为 Noto Serif SC 子集（SemiBold、Bold 各约 2.4 MB，覆盖 GB2312 全部字符、ASCII 和源码用字，OFL 许可证见 `assets/licenses`）。新增 GB2312 以外的字时，用 [`tools/fonts/make_serif_subset.py`](../tools/fonts/make_serif_subset.py) 重新生成。Noto Serif CJK 不带等宽数字特性，需要稳定宽度的跳动数字在阶段 3 单独处理。

### 阶段 1：外壳与导航

- 新底栏与 ＋ 新建面板，路由调整为今日 / 问答 / 资料 / 校园；起始页由“个人中心”改为“今日”（未见过登录页时仍先进登录页）。
- 去掉强制品牌屏，改用系统启动画面过渡。
- 在 `AndroidManifest.xml` 开启 `android:enableOnBackInvokedCallback`，为导航接入预测式返回；用共享元素转场容器包裹导航宿主。
- 问答与资料暂时指向现有页面，等第二、第三批设计完成后再改版。

### 阶段 2：今日

- 标题区：地平线组件（Canvas 绘制，含升起动画、轻点信息、长按预览）与标语引擎。
- “下一项”卡片、日期条、时间线行（节点样式、现在线、勾选三段动画、已完成折叠与撤销）、左右滑动切换日期、日 / 周切换与周课表重绘。
- 事项详情面板的容器变换；快速新建待办面板（复用 `AddTaskUseCase`）。
- 测试：下一项计算、标语规则、勾选状态序列。

### 阶段 3：校园、同步与成绩

- 校园页：账户卡、一键同步卡与统计、四个入口、后台提醒开关与间隔。
- 同步面板：四个来源依次显示运行、完成、失败状态；保持现有“单项失败不影响其余”和“重新同步全部”的行为。
- 成绩页：绩点滚动、学期柱、可展开课程行与位置条、本地估计说明、预测式返回。

### 之后

第二批（扫描、问答）与第三批（资料、设置含主题设置项、登录与导入、课程管理、考试、作业、空教室）定稿后，按同样方式实施。全部完成后删除 Terminal 组件、扫描线叠层和旧字体，并更新架构文档。

## 交互与逻辑调整

2026-11-15 起，项目所有者授权在改版中一并修正不合理的交互和逻辑。计划随对应阶段落地：

| 调整 | 原因 | 阶段 |
| --- | --- | --- |
| 已见过登录页后，起始页由“个人中心”改为“今日” | 打开 App 应先看到今天要做的事 | 1 |
| 去掉冷启动 1.3 秒的强制品牌屏 | 纯等待，没有加载任务需要它 | 1 |
| 提醒重排从“未来 24 小时”扩到未来 7 天，课表导入后立即排提醒 | 现状下长时间不打开 App 或刚导入课表时会漏提醒 | 2 |
| 一键同步支持“只重试失败项” | 现状失败一项要重跑全部来源，重复认证 | 3 |
| 课表导入在用户预览确认期间不再占用学校会话锁 | 现状下停在预览页会阻塞后台轮询和其他同步 | 3 |
| 退出登录时询问是否同时清除本机的成绩、课表与作业数据 | 现状只清凭据，换人登录时旧数据仍在 | 3 |

## 需要新增的逻辑

界面改版尽量只读现有数据，以下几处需要少量新逻辑：

| 内容 | 说明 |
| --- | --- |
| 天光主题引擎与主题设置 | 新的计算、偏好和主题层，不涉及数据库。 |
| 一键同步的最近完成时间 | 现有只记录“首次同步已完成”；“已同步 · x 前”需要新增时间戳偏好。 |
| 下一项与数据标语 | 读取已有日程、考试、作业与成绩数据的组合查询，不新增网络请求。 |
| 校园统计 | 课表节数、未完成作业、考试场数、成绩门数的计数查询。 |
| 只重试失败项 | 一键同步记录各来源结果，重试时只跑失败来源（见上表）。 |

本次改版不修改 Room schema，不需要数据库迁移。
